# Codex for OSS 项目支持说明

核对日期：2026-10-05。

OpenAI 的 [Codex for Open Source](https://developers.openai.com/community/codex-for-oss) 页面提供申请入口，说明维护者可申请六个月 ChatGPT Pro with Codex、条件性 Codex Security 访问，以及用于核心开源工作的 API credits。资格与批准由 OpenAI 审核，公开代码不自动获得支持。

## 可核实的项目材料

- 仓库：<https://github.com/Brighthao18/gantt-oss>。
- 许可证：MIT，维护者 GitHub 用户名：`Brighthao18`。
- 用途：面向课程、研究与个人项目的本地甘特图规划，支持可选自托管同步与提醒。
- 当前维护措施：贡献与安全说明、测试、GitHub Actions、依赖更新配置。
- Codex 辅助范围：开源准备、敏感文件分离、局部安全修复、文档和自动验证；维护者仍需负责审阅、问题判断与发布决定。

## 申请时由维护者补充

通过官方页面的 Apply today 入口，按表单提供真实身份、维护权限、使用规模与生态价值。用户数量、外部部署数和影响指标应有证据；本仓库不虚构这些数据，也不宣称达到“广泛使用”的门槛。

可以说明未来如何用 Codex 辅助问题分流、PR 审阅、回归测试与发布维护；这些是计划，不应写成已部署的自动化。提交申请前请本人阅读并接受项目条款。本次开源准备没有提交申请。
