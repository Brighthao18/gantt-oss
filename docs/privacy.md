# 数据与隐私

## 默认本地模式

项目、任务与本地档案信息保存在当前网站的 localStorage 中。应用不加载外部字体、统计脚本或维护者服务，也不自动向云端上传。本地服务器只监听 `127.0.0.1` 并提供明确列出的浏览器资源。

localStorage 未加密，同一浏览器使用者、具有相应权限的浏览器扩展与同源脚本可能读取。清除站点数据、换浏览器、换域名或端口会影响可用性。任务 PNG 是展示图片，不能恢复原始数据。

## 可选云端服务

配置 JSONBin 后，上传包含整个项目记录、任务备注及配置的通知邮箱。API Key、Bin ID、通知邮箱与主控 Bin ID 保存在当前本地档案中。Worker 从指定用户 Bin 或主控 Bin 读取数据，并通过 Resend 将任务名称、项目名、日期及备注发送到通知邮箱。

JSONBin、Cloudflare 与 Resend 会按各自服务条款处理请求与运行记录。请只配置自己管理的账户与明确同意的接收人。使用前核对服务所在地域、容量、费用与适用条款。

留空 API Key 并保存可关闭当前档案的云同步；关闭任务提醒或邮件方式可停止相应邮件。关闭本地同步不删除已经上传的数据，也不会撤销服务端 Worker 配置。需要彻底停止服务时，还应删除或停用 Worker 的用户列表、Cron 或部署，并在提供商控制台管理云端数据。
